## 🛡️ Executive Overview

**MULE SHIELD** is an enterprise-grade financial transaction intelligence platform focused on suspicious money movement analysis, topological circular loop tracing, and money mule syndicate detection.

Built for financial crime analysts, AML compliance units, and FinTech risk teams, MULE SHIELD delivers:
- **Louvain Modularity Partitioning ($Q = 0.642$)**: Mathematical community clustering discovering isolated, high-cohesion transaction pockets.
- **Topological Loop & Smurfing Detection**: Automated identification of circular layering cycles ($>95\%$ flow recirculation) and structured fan-out dispersal ($<\$10,000$ BSA threshold circumvention).
- **Multi-Agent Analytical Orchestration**: Four coordinated forensic agents synthesizing narrative findings, risk breakdowns, and audit trails.
- **Compliance Dockets & Certified Dossiers**: Interactive case management, printable regulatory reports, and CSV/JSON ledgers.

## 🚀 Single-Command Application Startup

Launch the complete application with:

```bash
npm start
```

### What `npm start` Does Automatically:
1. Detects and validates the Node.js and Python runtimes.
2. Starts the analytical Python backend on port `8000`.
3. Verifies backend REST API health (`/api/health`).
4. Serves the enterprise web application on port `3000`.
5. Automatically opens MULE SHIELD in your default browser.
6. Manages all background processes with clean termination on `Ctrl+C`.

> **Note:** If Node.js or Python is not pre-installed, MULE SHIELD can also be opened directly via `index.html` in any modern web browser. It features automatic standalone offline fallbacks with high-fidelity synthetic demo data.

1. **Overview Dashboard** — 6 financial KPIs, liquidity velocity bar charts, risk band distribution, Louvain Community Risk Heatmap, investigation priorities, and multi-agent streams.

6. **Investigation Cases** — Case docket management with linked entities, investigator notes timeline, and interactive `+ New Case Docket` creation modal.
7. **Reports & Exports** — Certified forensic dossier generation with official MULE SHIELD emblem header, printable regulatory styling (`@media print`), and one-click CSV and JSON data exports.
8. **Data Management** — Drag-and-drop CSV file ingestion, raw CSV text editor, pre-flight client-side schema integrity verification, and synthetic scenario loader.
9. **Settings** — Louvain modularity resolution ($\gamma$) slider, structuring threshold parameters, velocity relay windows, and full statutory legal disclaimers.
